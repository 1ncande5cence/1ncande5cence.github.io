\section{Research Interests}
\noindent My research focuses on systems and software security. I combine
program analysis with large language models to characterize security-relevant
program behavior. I use this approach to guide exploit generation, evaluate software
defenses, identify security-critical data, and detect security issues in
AI agent systems.
